# Lanes

Experiments in this repo are managed through **lanes**: one folder per experiment under `lanes/`.

Each lane is self-contained — it holds the experiment's notes, code, and assets, and its `README.md` starts with a status header:

```
Status: candidate | in-progress | done | dropped
```

## Lifecycle

1. **candidate** — an idea worth exploring, captured with enough context to pick it up later.
2. **in-progress** — actively being worked on.
3. **done** — reached a conclusion (working prototype or a documented "here's what we learned").
4. **dropped** — abandoned, with a short note on why.
